# MAKANLAB Reference-Matched Logo Pack

This pack rebuilds the supplied winged monumental M reference as scalable vector artwork.

## Files

- `makanlab-square-icon.svg` / `.png` — rounded-square outline plus M mark, transparent background.
- `makanlab-m-mark.svg` / `.png` — M mark only, transparent background.
- `makanlab-wordmark.svg` / `.png` — stacked M plus MAKANLAB, no tagline.
- `makanlab-signature-with-tagline.svg` / `.png` — optional full reference composition with tagline.
- `makanlab-square-icon-source-exact.png` — direct transparent extraction of the icon shown in the supplied JPG.
- `makanlab-m-mark-source-exact.png` — direct transparent extraction of the original M shown in the supplied JPG.
- `makanlab-wordmark-source-exact.png` — direct transparent extraction of the original mark and MAKANLAB lettering.

PNG sizes:

- Icon and M mark: 2048 × 2048
- Wordmark: 3600 × 1440
- Signature with tagline: 3600 × 1640

Palette: mint `#79F8C8`, cyan `#08E7E5`, electric blue `#08A8FF`, royal blue `#2869F5`.

Use the `source-exact` PNGs when matching the supplied reference literally. Use the SVG files when you need infinitely scalable, clean-edged artwork; those are faithful vector redraws because the supplied source was a compressed JPG rather than original vector artwork.
